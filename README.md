# OnScreen Clock
OnScreen Clock: a desktop clock above the taskbar, digital or analogue



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* Switch between Analogue and Digital clock
* Shown in the bottom-right corner of the screen, above the taskbar
* Tray icon menu: Digital, Analogue, Config, Exit
* Config: choose the clock that is shown at start (saved to an .ini file)
* No taskbar button
* Native Win32/Win64 app: no runtime needed
